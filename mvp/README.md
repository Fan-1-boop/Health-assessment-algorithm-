# 单数据集卫星健康度算法 MVP（模拟数据版）

**范围冻结：一个模拟卫星数据集，一次训练/校准/测试，输出可重复的模型指标与可直接检查的逐时刻预测。不要把模拟故障分类结果当成真实卫星设备诊断精度。**

## 适用目的

这是可交付的算法最小实现（无 App、无自动在线更新）：

\`\`\`text
模拟卫星8路原始传感器 + 真实生成的H/D/F与异常标签
├─ 32点因果窗口 -> 400维工程特征 -> 两次独立MSF-MOFS特征选择
│                                      -> 两级健康状态逻辑回归
│                                      -> 校准 + 判别式HMM -> 三状态基础概率
└─ 原始8路时序因果窗口 (不使用MSF特征) -> RandomForest -> 异常证据概率

HMM状态概率 + 异常证据 -> 校准任务集上训练的简易多分类Logistic融合
-> 三级最终概率 -> 默认 0–100 分映射 -> 模拟操作员评分校正映射
-> 逐时刻概率、异常标记、健康分和模拟反馈文件
\`\`\`

状态 \`Healthy_simulated/Degraded_simulated/Fault_simulated\`、传感器异常、维修反馈、操作员评分**全由固定模拟器自动生成**。传感器存在周期性运行工况切换与少量正常特殊事件；不要用模拟结果证明真实设备的故障判定或维修效率。

## 一键运行

在仓库根目录运行：

\`\`\`bash
python -m pip install -r requirements.txt
python -m pip install joblib
python -m pytest -q mvp/test_mvp.py
python mvp/run.py --out results/mvp
\`\`\`

使用固定 seed=20261016、4 个模拟任务段、每段 1200 点、8 路原始遥测，训练段 mission 0+1、独立校准/简单融合段 mission 2、最后展示测试段 mission 3。每段按 4 个运行周期切分因果窗口，不跨任务段和周期使用观测值；真实标签已经内置于数据生成器，不采用历史 SMAP 20%/80% 区间位置代理标签。

400 个特征来自 5 个不同长度 × 10 类时序统计 × 8 路传感器。两级 MSF-MOFS 使用仓库已有的 Fisher 引导 NSGA-II 工程适配模块；**不是**原论文的完整参数配置或 5-NN 包装式算法复现。

## 交付文件

运行后位于 \`results/mvp/\`：

- \`synthetic_satellite_telemetry.csv\`：完整单数据集，含传感器、模拟状态、模拟异常、运行模式及人工评分真值。
- \`demo_predictions.csv\`：测试集逐窗口的三级概率、异常概率/告警、最终 0–100 健康分、模拟状态标签。
- \`simulated_feedback.jsonl\`：72 条模拟操作员评分及数据来源标记。
- \`metrics.json\`：静态分类、HMM、异常检测、融合分类、健康评分的全部保留测试指标及特征选择统计。
- \`model_bundle.joblib\`：训练好的二级概率估计器、HMM 参数、特征索引、异常检测器、融合器和评分映射（只在可信环境加载）。
- \`RESULTS.md\`：中文实验结果摘要。

GitHub Actions 工作流：\`.github/workflows/mvp_synthetic.yml\` 自动安装依赖、运行测试与实验、提交结果数据。由于每项指标来自单一模拟生成机制，不主张跨数据集泛化能力。

## 评价原则

保留任务段级未参与训练的测试数据；不为追求高指标反复更换模拟规则或随机种子。若模型效果一般，也如实报告。HMM 是判别式后验/先验修正的时序近似，不是完整生成式 DBN。融合采用简单 Logistic stacking，模拟操作员评分**只更新最后的评分映射**，不改状态概率。
