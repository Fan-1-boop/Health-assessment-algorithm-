# 卫星健康度算法 MVP（全模拟数据）实验结果

**声明：所有健康状态、故障、异常与操作员校正分数均由程序模拟，非真实卫星故障验证。**

单数据集：4800 条遥测、8 个原始通道、400 个工程特征；训练/校准/测试窗口：544/272/272。

| 模块 | 测试结果 |
|---|---:|
| 两级静态分类 Macro-F1 | 0.9718 |
| 两级分类 + HMM Macro-F1 | 0.9782 |
| 独立异常检测 AP | 1.0000 |
| 独立异常检测 F1 | 1.0000 |
| 后期概率融合 Macro-F1 | 0.9813 |
| 默认映射健康分 MAE | 7.960 |
| 模拟校正健康分 MAE | 2.623 |

两级 MSF-MOFS 从 400 维分别选取 50 和 10 维特征，去重后 59 维。训练时正常健康状态与退化/故障状态由两个独立二分类器建模。

测试概率和指标可以在 metrics.json 和 demo_predictions.csv 中逐条核对。自动人工校正只更新 0-100 健康分数的有序映射，不修改概率模型。全部测试来自同一合成生成器的未参与模型训练任务段，不代表真实应用效果。
