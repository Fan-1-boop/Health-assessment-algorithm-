# V1.2：先分别验证动态贝叶斯和时序异常检测，再决定是否融合

## 数据与真实标签

- NASA SMAP P-1，使用仓库保留的公开目标通道原始时序和 Telemanom 异常区间，固定 64 点因果窗口。
- 唯一真实目标是“遥测异常 / 正常”二值标签。`configs/proxy_label_rules_v1.json` 已先前冻结，健康 / 退化 / 故障三个状态来自异常区间位置规则，**并非卫星物理故障真值**。
- 时间顺序训练 `<2600`、验证 `[2600,4000)`、测试 `>=4000`，不得按测试性能修改规则、模型选择或阈值。
- P-1 的三段时间内各只有一个异常事件；事件级泛化不足，报告有明显不确定性。健康标注、操作工况和具体故障类型缺失。

## 分支一：动态贝叶斯概率（代理状态）

1. 从原始序列的 64 点历史生成 510 维多尺度统计、频域、变化率等特征。
2. MSF-MOFS **分别**进行两次二分类多目标选择：`healthy / unhealthy` 使用全部训练样本；`degraded_proxy / fault_proxy` 只使用不健康训练样本。两次特征子集可以不同。使用相同的预先冻结标签，不能改变规则来追求好看的指标。
3. 两个二分类逻辑回归模型输出两级概率，通过乘法规则生成三个状态概率。对平衡类别权重造成的偏移进行近似先验校正，并保留未校正模型的对照。
4. 从训练标签的时间顺序估计转移矩阵。在两级分类器输出的基础上，测试**判别式概率转似然的 HMM 近似**；同时测试单独训练的 **PCA + 对角高斯观测分布的生成式 HMM**。HMM 用正向滤波并遵守时间因果性。
5. 所有 HMM 超参数只在验证集调节。评价三级代理状态 Macro-F1、Balanced Accuracy、Brier、混淆矩阵，并与 510 维静态模型及两级 MSF 静态模型比较。

**验收要求**：相较于 MSF 静态模型，HMM 至少在验证集的联合目标上改善；最终保留测试集 Macro-F1、Brier 的全部对照。不满足时明确标记失败，而不是强行认为 HMM 有增益。

## 分支二：真实异常检测

1. 输入是 64 点原始遥测序列；仅使用窗口内部的值、差分、局部统计作为输入编码，不引入未来信息。
2. 训练多个**有监督**候选：随机森林、极端随机树、线性逻辑回归、RBF-SVM、直方图梯度提升；同时独立给出以正常参考数据训练的 Isolation Forest 无监督基线。
3. 训练样本使用时间划分的训练段与公开正常预训练段；**验证集 AP（PR-AUC）** 用于选模型，验证集 F1 用于定阈值，**测试集绝不能用于选模**。
4. 保存验证模型排序、保留测试 AP、ROC-AUC、F1、precision、recall、假阳性/漏报次数；比较测试 AP 与测试异常发生率。

**验收要求**：若测试 AP 未明显超过异常基准发生率、误报无法接受或跨异常事件失效，标注“检测性能未达标”；将此分支继续作为单独的研究问题，不接入融合。

## 明确暂缓的工作

本轮**不**训练联合融合模块、不优化健康度映射、不改变模拟用户或维修反馈逻辑、**不**执行在线增量更新。必须先验证真实卫星异常检测和代理状态时序模型各自的性能；随后再扩展至真正包含多事件和多通道遥测的评估。

运行：

```bash
pip install -r requirements.txt
pytest -q
python scripts/run_v12.py --generations 5 --population 12
```

完整结果：`results/v12/RESULTS.md`、`metrics.json`、`heldout_predictions.csv`；GitHub Actions `experiment_v12.yml` 自动保存实验工件。
