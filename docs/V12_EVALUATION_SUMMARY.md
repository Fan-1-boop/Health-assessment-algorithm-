# V1.2 独立分支验收结论（2026-10-16）

> **两条分支尚未通过模型性能验收；停止概率融合研究直到问题解决。** GitHub Actions green 仅表示训练、测试和结果导出成功，不代表卫星故障诊断模型具有实际可用性能。

## 已实现
- 基础状态分支：510 维因果工程特征；对健康/不健康、退化代理/故障代理分别执行二分类 MSF-MOFS；两级逻辑回归；判别式 HMM 与带独立高斯观测分布的生成式 HMM。
- 异常检测分支：原始 64 点时序训练 RandomForest、ExtraTrees、LogisticRegression、RBF-SVM、HistGradientBoosting；IsolationForest 仅作无监督基线。
- 严格使用时间划分：训练 2,537，验证 1,400，保留测试 4,505；测试异常 309（6.86%）；验证集选模型、调门限。
- **没有执行两分支融合，没有做增量更新，没有用模拟健康度分数“训练”本轮分支。**

## 基础状态分支（测试集：冻结代理状态）
| 对照 | Macro-F1 | Multiclass Brier ↓ |
|---|---:|---:|
| 全 510 维两级静态 | 0.38473 | **0.135249** |
| 两级 MSF 静态 | 0.35457 | 0.161354 |
| 两级 MSF + 判别式 HMM | 0.35720 | 0.166044 |
| 两级 MSF + 生成式 Gaussian HMM | **0.41077** | 0.328585 |

两个 MSF 阶段分别选择 30、10 维，在线特征并集仅 34 维。生成式 HMM 虽然 Macro-F1 高于静态基线，但 Brier 明显变差，且**退化代理类别 61 条测试样本没有一条被正确识别**。这不构成状态模型已调好的证据。

## 异常检测分支（测试集：真实公开异常区间）
验证集 AP 最高的 RBF-SVM：验证 AP **0.733438**，独立测试 AP **0.052886**，ROC-AUC **0.393512**，阈值下故障召回 **0**，误报 **144**。这一跨异常事件泛化失败是本轮最重要的负面结果。测试阳性基线 **0.06859**，选定模型 AP 反而更低。

事后诊断性对照中，随机森林测试 AP 0.109878，是本轮最高的测试 AP，但**不得利用这一测试结果反过来选择随机森林并宣称完成了无偏选模**。

## 失败原因与下一步
本轮仅使用 SMAP P-1 一个目标遥测通道，训练 / 验证 / 测试各含一个异常事件，导致验证事件的优秀表现不能代表跨事件泛化。要改善异常分支，需要扩展 NASA SMAP 多通道、多异常事件的数据集，并优先进行跨事件、跨通道验证。下一步要求严格报告保留测试 AP、虚警、召回。

此外，公开 SMAP 数据不提供真实“退化/故障”物理标签，当前三级状态来自固定异常区间位置规则，因此即使代理分类性能提高，也不能验证真正的卫星故障诊断或健康度分数。需要有可信状态序列、维修/故障结果时才能进行有意义的物理健康状态 HMM 研究。

**结论：代码和独立实验实现完毕，但两个模型尚未达到融合前应有的可靠性；下一轮仍应分别改进模型及数据基础。**
