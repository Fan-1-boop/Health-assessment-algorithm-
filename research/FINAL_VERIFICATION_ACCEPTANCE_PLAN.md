# 最终验证与验收路线 v1.0（研究阶段冻结目标）

**冻结范围：单一卫星数据源、双分支原有框架、MSF-MOFS 既定预算、严格区分真实数据与模拟证据。**

本文件记录下一阶段目标与验收规则，不表示最后的验收已执行或通过；具体专利技术差异化公式、源代码和待申请权利要求不放到公开 GitHub 研究分支。

## 1. 技术路线固定

1. 状态分支 A：遥测特征 → MSF-MOFS → 两级健康/非健康及退化/故障分类器 → 概率校准 → HMM 时序滤波。
2. 异常分支 B：遥测片段 → 独立异常检测器；仅可信的正常/异常标签可更新这条候选分支。
3. 融合与健康评分：在概率语义兼容且通过验收时才使用候选异常证据；必要时重新校准融合器；最后输出三级状态概率与0–100分数。
4. 人工监督版本治理：人工可信标签与溯源 → 候选定向更新 → 分支接口检查 → 同条件性能门控 → 人工审批/回退。绝不进行未审核数据的自训练或自动上线。
5. MSF-MOFS 在真实 OPS-SAT 2,578 维研究中**固定预算上限64维**，此前实际选中37维；表述为“实验得到的较好成本—性能折中配置”，不得称“全局最优”。已有冻结模拟 400 维状态分支沿用分别选中50维和10维（并集59维），不伪称应用过真实数据64维预算。

## 2. 最终主数据与证据边界

唯一计划使用的真实卫星数据源：**OPS-SAT-AD，2,123个有标签片段**，官方训练1594段、官方测试529段；真实原始时序约303,493个采样值。官方标签只有**正常/异常二分类**，没有经核实的健康/退化/故障三状态物理标签、时间转移真值，也没有人工0–100健康分真值。

完整 HMM/双分支融合及评分的证据必须使用既有固定模拟卫星时序，明确报告为**模拟系统级验证**。不能把 OPS-SAT 二分类准确率当作真实三级诊断准确率。跨卫星/跨数据集迁移学习作为未来方向，不列入本项目验收。

此前冻结的真实卫星二分类参考结果（官方 test=0，n=529，113个异常）：18个预统计特征 + HistGradientBoosting，**F1=0.9082569、AP=0.9648411、Recall=0.8761062、正常误报6/416**。这些是既有交付记录，不是本轮高维预算或监督更新的结果。官方测试集此前已被评阅，后续只可在预冻结版本/模型后作为**同数据集的有历史使用记录的最终基准检查**，不可宣称首次不可知盲测。

## 3. 最终真实数据验证如何做

真实 OPS-SAT 原始官方训练集（train=1）内部，按片段唯一 ID 隔离旧模型拟合、新标签模拟上传、阈值校准、候选更新验收；检查同通道/近邻时序的潜在重叠或强相关风险。不得把随机划分直接等同时间上独立的卫星新工况。全程保留数据 SHA-256、训练配置、随机种子、标签来源、环境版本、预测结果和代码版本。

预先冻结两个相互独立的验证问题：

**A. 正常/异常识别性能与特征成本。** 固定高维特征提取定义、预算上限64及已确定的模型配置，比较全部2578维、常规 Fisher 特征筛选和预算64 MSF-MOFS 在**同样分区与同一分类器**上的表现；报告维度、F1、AP、Recall、FPR、训练/预测时间、选特征搜索时间和特征提取成本。不得因结果不理想改预算，也不要求比全部方法都好。

**B. 可信标签驱动的受控更新。** 在原 train=1 中以已有的 OPS-SAT 二分类专家标签模拟一个新增人工监督批次；标注来源必须写作“已有标签重组的模拟人工上传”，而不冒充真正新收到的卫星人工审核数据。比较 A=冻结旧检测器、B=普通监督重训、C=候选质量/接口门控并在不通过时保留A、D=如有新增差异化机制且已完成IP保护时的私有候选。所有方法共用**相同的新标签和独立验收集**。不把二分类标签用于训练真实三级/HMM状态分类器。

当存在同源数据的原官方 test=0 最终基准时，只可在**算法/阈值/验收规则全部锁定之后**读取/评估，不反复通过其结果选择更新方式或特征预算。公开历史测试曾被查看过，必须在论文中承认，不能制造数据首次盲测印象。

## 4. 最终验收分两层，不混淆

### 第一层：研究原型验收（本项目目标）

必须同时满足：
- 源码+固定协议+依赖版本+预测文件+模型摘要可复现，CI及质量校验/回退测试通过。
- 固定结构的模拟三级状态分类/HMM/融合消融完整；宏F1、逐类召回、Brier、NLL、状态切换延迟、模拟健康分MAE和推断成本均列出，含负面指标与局限。
- 在真实 OPS-SAT 上复现正常/异常二分类性能，且 MSF 64预算特征方案与全特征/Fisher 在相同划分下给出完整性能—时间折中表；不要求虚构压倒性优势。
- 真实数据已有可信标签的受控更新 A/B/C 有实际可重复实验，正常样本误报和异常漏检不得被单一F1掩盖。候选回退时原版本概率输出与版本标识可核实不变。
- **错误标签漏检不能被隐去。** 先前模拟实验存在“全部翻转标签通过常规门控、最终Brier/NLL恶化”的已知失败。最终验收必须报告这个案例，并将未被可靠识别的标签列为“需人工复核/不可自动安全批准”，而不是声称所有错误都能自动识别。
- 任何专利候选算法的实验须有与普通重训/融合重校准相同数据条件下的对照；需列出失败、额外训练成本及边界。若无可重复正向增益，如实记为创新机制未通过，不影响常规MVP工程成果的记录。

**量化容差如何锁定：**在最终候选实现之前，依据真实 OPS-SAT 官方训练集内部的校准/验收结果和应用损失，预登记 Macro-F1/F1、AP、Recall、FPR、Brier/NLL 的容差与候选拒绝条件。不能在看到最终原官方测试指标以后临时调整容差。本文件不凭空承诺某个绝对F1或误报改进幅度。

### 第二层：真实业务/生产验收（不应误称已通过）

必须另有真实受权人工审核、标签审核留痕、应用场景的数据更新授权、生产版原子发布/回滚、可信运行数据、实际故障语义与相应工程可靠性认证。现在均不在已完成证据内。不得将第一层研究演示当作真实卫星自主健康保障系统已上线。

## 5. 期望论文与专利如何表达创新

- 技术架构是一种**面向卫星健康状态估计和异常检测、分支监督更新、概率接口校验与人工版本控制的整体组合**。其价值在于任务分工、反馈闭环、成本与性能之间的工程权衡、概率接口维护和可审计的更新流程。
- **架构组合有工程价值不等于法律上自动具备新颖性/创造性**。普通MSF、分类器、HMM、逻辑融合、人工审核各自既有技术；专利应聚焦一个能具体定义并由消融对照证明效果的“区别技术特征”，且进行现有技术检索，由专利代理人审阅。
- 针对真实数据仍只能主张异常二分类与人工标签更新的相关技术效果；模拟状态证据可支持整个方法的实验性可行性，不能挪用为真实物理故障识别的客观证明。
- 不追求每个模块单独第一名。对 MSF看特征压缩率/训练代价/分类损失，对HMM看概率校准与时序状态稳定，对融合看多分支概率正确性，对监督更新看错误更新风险/回退与算力开销。
- 原创候选如有专利披露敏感内容，先放私有环境，在申请前不要通过公开GitHub或论文泄露实现细节；正式专利递交时机需要IP专业审查。

## 6. 明确停止扩展范围

不再扩大特征预算搜索、不更换数据集追求更高指标、不把新分类器堆叠当作创新、不启动迁移学习、不重复修改交付冻结分支、不将模拟“人工审核”伪装为真实审核。

**研究分支：** `research/hitl-quality-gated-update`。
**冻结交付：** `release/delivery-mvp-v1.0-frozen`。
**下一动作：** 在私有环境检验最小可论证区别机制并给出与普通基线同条件对照；形成固定版本后，才开始 OPS-SAT 上的最后真实二分类/监督更新验证和最终验收记录。
