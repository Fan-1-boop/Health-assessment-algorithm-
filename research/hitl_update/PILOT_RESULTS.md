# 人工有标签数据受控更新：公开基础实验 v0.1

> **状态：工程基线验证完成；专利算法创造性尚未证明。**
> 本文件及源码仅包含常规监督学习、质量校验与发布审核框架。任何潜在专利差异化规则均未在公开仓库实现或披露。

## 1. 数据和模拟上传条件

数据：真实 OPS-SAT-AD 官方异常检测数据集。使用 **官方 train=1 的 1,594 个已标注片段**构造内部独立分组：

| 内部子集 | 片段数 | 用途 |
|---|---:|---|
| 历史训练 A | 876 | 旧监督模型拟合 |
| 新有标签批次 | 319 | 从原有公开数据中抽取的模拟人工上传 |
| 独立验证 | 239 | 只用于新候选的门控、分类阈值及更新验收 |
| 独立审计 | 160 | 只用于最终对照 |
| **官方原始 test=0** | **529** | **本实验完全排除，不使用** |

重要说明：这 **319 个样本不是新的人工标注**，而是 OPS-SAT 原始已有的专家参与标注数据。为了测试提交接口，实验将它们重新包装为一份 **SIMULATED_REVIEW** 上传示例，且只允许显式开启测试开关。**此流程不代表有真实操作员重新确认了样本，也不具有生产发布授权。**

不使用虚拟三状态标签。此批数据只能更新候选 **正常/异常二分类分支**，不得用于物理健康/退化/故障分类器或真实健康分数映射。

## 2. 普通对照方案（不称为发明）

- A 不更新：HistGradientBoosting 仅拟合历史训练集。
- B 普通监督重训：相同配置下，拟合历史训练集 + 新批次的全部 319 份原有标签。
- C 受控更新候选：先对标签类型、来源标记、审核状态、去重、保留集交叉、预期父模型、特征缺失和批次 SHA-256 做常规校验；然后使用和 B **完全相同**的候选模型，根据**相同的验证集**进行普通保留/回退判定。C 不是新模型的算法优化器。
- A、B 选择各自验证集上的 F1 最优阈值；各自最后以冻结阈值评价独立审计集。
- C 候选是否允许进入**后续人工审批**不等于“生产发布”。本实验所有候选的 release_allowed=false，未切换任何交付版本。

## 3. 实际运行结果

GitHub Actions: https://github.com/Fan-1-boop/Health-assessment-algorithm-/actions/runs/38913760102

| 方案 | 验证 F1 | 审计 F1 | 审计异常 Recall | 审计正常误报率 |
|---|---:|---:|---:|---:|
| A 旧模型不更新 | 0.9474 | 0.8070 | 0.7188 | 0.0156 |
| B 普通监督重训 | 0.9474 | 0.8525 | 0.8125 | 0.0234 |
| C 质量门控的受控候选 | 0.9474 | 0.8525 | 0.8125 | 0.0234 |

B/C 相比 A，在审计集上漏检数量从 9 下降到 6，普通正常误报数量从 2 上升至 3。由于审计集只有 160 片段，其中正常 128、异常 32，这些数字只支持小规模探索性比较，不能做稳定性或显著性断言。

C 在验证上符合预登记的普通 F1、召回、正常误报率保留规则，因此候选可以**进入等待人工审批状态**，但 release_allowed=false、new_model_deployed=false。因为 C 实际使用的候选与 B 相同，二者审计指标完全相同。

**不允许宣称 C 优于 B 或 C 具有独立专利创造性。**

## 4. 本轮质量门控的覆盖范围

现有单元测试覆盖：
- 未经审核或伪标签拒绝；
- 模拟审核默认禁止，测试中须明确开启且不可伪装生产批准；
- 上传数据 SHA-256 不一致拒绝；
- 重复样本、与保留验证/审计集重叠拒绝；
- 缺失特征超标、过期父模型拒绝；
- 仅二分类标签不能进入真实三级状态更新；健康评分单独路由；
- 时间序列数据缺少采样时间信息时拒绝。

**当前不具备真实人工身份认证、业务审批 UI、物理故障真值核验和生产版本自动切换**。单纯在 JSON 中填写 reviewer_id 或 approval_status 无法证明人工身份或授权。

## 5. 对下一步创新研究的约束

此次对照没有新增真实工况改变，更没有证明“避免把工况变化误判成故障”的技术效果。下一阶段所需的，是一个**具备可信的正常工况切换与真实故障区分标签**的数据批次，以及改进方案与普通监督重训在**相同标注数据、相同评估集**上的直接比较。

考虑公开专利披露风险，具体的差异化概率一致性更新机制、数学公式和拟申请的权利要求须先在私人环境完成研究或由专利代理师确认公开时机。

## 复现

在研究分支上：

\`\`\`bash
python -m pip install -r requirements.txt
python -m pip install joblib
python -m pytest -q research/hitl_update/test_gate.py
python research/hitl_update/ablation.py --out results/hitl_public_pilot
\`\`\`

\`results/hitl_public_pilot/metrics.json\` 保存验证、审计和门控结果；\`candidate_only.joblib\` 是**未审批候选模型**，不是交付产物，不应部署。
